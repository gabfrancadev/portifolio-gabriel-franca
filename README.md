### Molaris — Em desenvolvimento (MVP completo)

Sistema SaaS multi-tenant (Web + PWA) em arquitetura monorepo para gestão de clínicas odontológicas, desenvolvido em colaboração.

- Agenda semanal, prontuário eletrônico append-only (conforme CFO 2026) e pré-check-in via QR Code.
- CRM Kanban com alertas de recall de 6 meses e agendamento online público.
- Contas a pagar, fluxo de caixa, estoque clínico, relatórios, metas de equipe e hardening de segurança com logs LGPD.
- **Stack:** Next.js, Tailwind CSS, PWA, Express, Prisma, PostgreSQL e Docker (deploy preparado para Render + Vercel).
